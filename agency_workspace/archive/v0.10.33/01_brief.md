# Project Brief

## Business Goal
The client requires the following updates to the Antigravity Plugin:
1. **Editable Settings**: Make the autonomy mode and the Antigravity Link port editable directly within the settings tab.
2. **Step-by-Step Mode**: Modify the behavior of the application by implementing a step-by-step mode. The "Run Agency" button should advance the workflow prompt-by-prompt. It must pause and leave the user time to read the conversation, wait for the user to press a "continue" button, and only then send the next prompt to the appropriate destination.

## Constraints
- **Timeline**: No time limit.
- **Budget**: Unlimited budget.

## Success Criteria
- The autonomy mode setting is editable in the settings UI.
- The Antigravity Link port is editable in the settings UI.
- The agency run functionality fully supports a step-by-step execution mode requiring user input ("continue") to advance the workflow prompt-by-prompt.
